# RAG 성능 평가 가이드

## 📋 평가 계획

**목표:** BM25 vs Dense (E5-base) vs Hybrid 비교

### Phase 1: Retrieval 성능 평가
- **평가 대상:** BM25, Dense (E5-base), Hybrid (α=0.7)
- **메트릭:** Precision@K, Recall@K, MRR, NDCG@5
- **소요 시간:** 약 30-40분

### Phase 2: RAGAS 평가
- **평가 대상:** BM25-RAG (전체 파이프라인)
- **메트릭:** Faithfulness, Answer Relevancy, Context Precision/Recall, Citation Accuracy
- **소요 시간:** 약 1-2시간

### Phase 3: 결과 분석
- **기능:** 종합 표 생성, Excel 내보내기
- **소요 시간:** 1분

## ⚙️ 기술 세부사항

### 모델 선택

**Dense Model: intfloat/multilingual-e5-base**
- 크기: 278M parameters
- 차원: 768
- 장점:
  - ✅ 한국어 지원 우수
  - ✅ BM25와 비교 가능한 성능
  - ✅ 적당한 크기 (메모리 안전)
  - ✅ Microsoft 공식 모델

### GPU 최적화

1. **FP16 (Mixed Precision)**
   - GPU 메모리 50% 절감
   - 속도 2배 향상

2. **청크 분할**
   - 5,000개씩 나누어 임베딩
   - 메모리 안전성 확보

3. **배치 크기**
   - GPU: 32
   - CPU: 8

## 📊 평가 메트릭 설명

### Phase 1 메트릭

- **P@1, P@3, P@5**: 상위 K개 중 관련 문서 비율
- **R@5**: 전체 관련 문서 중 검색된 비율
- **MRR**: 첫 관련 문서 순위의 역수
- **NDCG@5**: 순위를 고려한 검색 품질

### Phase 2 메트릭

- **Faithfulness**: 답변이 검색 문서에 근거 (높을수록 환각 적음)
- **Answer Relevancy**: 답변이 질문과 관련성
- **Context Precision**: 검색 문서 정밀도
- **Context Recall**: 필요한 문서를 모두 찾았는지
- **Citation Accuracy**: 정답 법률 조문 언급
