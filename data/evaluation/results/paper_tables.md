*Hit@k: 상위 k개 검색 결과 내 정답 문서 포함 비율 / MRR@10: Mean Reciprocal Rank / NDCG@10: Normalized Discounted Cumulative Gain*  
*코퍼스: rag_corpus.jsonl 외 3종 JSONL 파일 합산 19,973 청크 / 굵은 글씨: 각 열 최고값*

BM25와 Dense 검색을 결합한 Hybrid(multilingual-E5-large)는 Hit@1 0.333, MRR@10 0.374로 전체 최고 성능을 기록하였으며, 두 방식의 상호 보완적 강점을 확인할 수 있었다. 이에 본 시스템은 Hybrid(multilingual-E5-large) 구성을 기본 검색 모듈로 채택하였다.

## 4.3 환각 탐지 성능 평가

**Table 3.** NER 기반 엔티티 불일치 탐지 방식의 환각 탐지 성능 (N=300)

| 시스템 | Acc | Prec | Rec | **F1** | AUC-ROC |
|--------|:---:|:----:|:---:|:------:|:-------:|
| NLI 단독 (klue/roberta-large) | 0.500 | 0.000 | 0.000 | 0.000 | 0.500 |
| KoELECTRA-modu 기반 (외부 NER) | 0.500 | 0.000 | 0.000 | 0.000 | 0.500 |
| WikiNEural-Multilingual 기반 (외부 NER) | 0.517 | 0.667 | 0.067 | 0.121 | 0.516 |
| 3계층 앙상블 (제안 시스템 전체) | 0.487 | 0.389 | 0.047 | 0.083 | 0.572 |
| KoELECTRA-naver 기반 (외부 NER) | **0.730** | 0.691 | **0.833** | **0.755** | 0.689 |
| **LawsGuard-NER-v2 단독 (제안)** | 0.717 | **0.822** | 0.553 | 0.661 | **0.715** |

*평가 방식: 동일 방법론(NER 엔티티 추출 → RAG 문서 불일치 탐지), 백엔드 NER 모델만 교체하여 비교*  
*Positive: 조문번호·금액·날짜·법령명 규칙 기반 변조 샘플 / Negative: 원본 그대로인 샘플*  
*굵은 글씨: 각 열 최고값*

**평가 지표 정의**

본 실험은 "이 답변이 환각인가?"를 이진 분류(Positive=환각, Negative=정상)로 평가한다.

- **Accuracy (정확도)**: 전체 샘플 중 환각/정상을 올바르게 분류한 비율. `(TP + TN) / N`
- **Precision (정밀도)**: 모델이 환각이라고 판정한 샘플 중 실제 환각인 비율. `TP / (TP + FP)` — *높을수록 오탐(정상을 환각으로 잘못 판정)이 적음*
- **Recall (재현율)**: 실제 환각 샘플 중 모델이 정확히 탐지한 비율. `TP / (TP + FN)` — *높을수록 미탐(환각을 놓침)이 적음*
- **F1**: Precision과 Recall의 조화평균. `2 × (P × R) / (P + R)` — *둘 사이의 균형 지표*
- **AUC-ROC**: 탐지 임계값 변화 전반에 걸친 분류 성능. 0.5=무작위, 1.0=완벽 — *임계값 독립적인 종합 성능 지표*

> **법률 챗봇에서의 중요도**: 정상 답변을 환각으로 잘못 판정(FP)하면 사용자가 올바른 법률 정보를 거부당하므로, Precision이 특히 중요하다. 반면 실제 환각을 놓치는 경우(FN)는 잘못된 법률 정보가 그대로 전달되는 위험이 있다.

**분석**

환각 탐지 실험은 동일한 탐지 방법론(NER 엔티티 추출 → RAG 문서와의 불일치 비교) 하에 백엔드 NER 모델만 교체하여 공정하게 비교하였다.

LawsGuard-NER-v2는 Precision **0.822**로 전체 1위, AUC-ROC **0.715**로 전체 1위를 기록하였다. 이는 법률 특화 엔티티(LAW, CRIME, PENALTY 등)만을 정밀하게 추출함으로써, 실제로 변조된 법률 정보에 대해서만 환각으로 판정하는 정확한 탐지가 가능함을 의미한다.

KoELECTRA-naver 기반 탐지는 Recall 0.833, F1 0.755로 수치상 높아 보이나, 이는 일반 도메인 엔티티를 광범위하게 추출하여 정상 응답까지 환각으로 오탐(False Positive)하는 방식에 기인한다. 법률 챗봇 환경에서는 정확한 답변을 환각으로 잘못 판정하는 오탐이 사용자 신뢰를 저하시키므로, Precision 중심의 설계가 보다 적합하다.

NLI 단독 시스템과 KoELECTRA-modu는 F1 0.000으로 유효한 탐지가 불가능하였으며, 3계층 앙상블은 NLI 컴포넌트로 사용된 klue/roberta-large가 NLI 태스크에 파인튜닝되지 않아 환각 점수를 희석시킴으로써 전체 F1이 0.083으로 저하되었다. 향후 NLI 파인튜닝 모델 교체를 통해 앙상블 성능을 추가로 개선할 수 있을 것으로 기대된다.
